# NexusPad

Customizable virtual controller and keyboard overlay mapper for **GeForce NOW** cloud gaming on Android.

## Features
- **Interactive Layout Studio**: Drag, resize, reshape, recolor, and tune opacity for virtual buttons, dual analog sticks, D-Pads, WASD clusters, and shoulder paddles.
- **Controller & Keyboard Bindings**: Map touch inputs to Xbox/PlayStation gamepad buttons, analog axes (`AXIS_X/Y`, `AXIS_Z/RZ`), PC keyboard keys (`WASD`, `Space`, `Shift`, `Ctrl`, `Tab`, `Esc`, `1–6`, `F1–F9`), and multi-key combos (`Ctrl+G`, `Shift+Tab`, `LB+RB`).
- **Trigger Modes**: Supports **Hold**, **Toggle** latch, and **Turbo** rapid-fire (`4–20 Hz`), plus deadzone and sensitivity calibration.
- **Profile Library & JSON Import/Export**: Preloaded with GeForce NOW starter presets (*FPS Precision*, *Action RPG + Hotbar*, *Hybrid WASD + Hotkeys*, *Racing Telemetry Pad*) and full JSON backup/sharing.
- **Floating Overlay & Test Sandbox**: Live `SYSTEM_ALERT_WINDOW` touch-passthrough overlay + `InputMethodService` key dispatch + built-in Stream Test Sandbox with real-time `KeyEvent`/axis telemetry.
